# Transform Studio

Интерактивная лаборатория теоретико-множественной геометрии: возьми произвольную
векторную фигуру, деформируй её мышью и смотри, что с ней делают операции над
множествами точек — вживую, с анимацией построения.

Появилось из [видео](difference_sets.py) (Manim) про разностные множества
контуров — вместо готового ролика живой стенд для экспериментов.

## Операции

| Операция | Определение |
|---|---|
| Разностное множество | D = {p − q : p, q ∈ A} |
| Расширение (dilation) | A ⊕ B = {a + b : a ∈ A, b ∈ B} |
| Эрозия (erosion) | A ⊖ B = {x : x + B ⊆ A} |
| Открытие | (A ⊖ B) ⊕ B |
| Закрытие | (A ⊕ B) ⊖ B |
| Выпуклая оболочка | conv(A) |

B — структурирующий элемент (круг с настраиваемым радиусом или квадрат).

## Возможности

- **Произвольные фигуры:** загрузка SVG (собственный парсер: `path` со всеми
  командами включая дуги и S/T-отражения, `rect`/`circle`/`ellipse`/`polygon`,
  вложенные `transform`) или пресеты (круг, квадрат, треугольник, звезда, L-фигура)
- **Деформация мышью:** тащи вершину контура — результат пересчитывается в реальном времени
- **Анимация построения:** пары p−q со стрелками → облако разностей → проявление
  залитой области; с прокруткой (scrubber) и пуском/паузой
- **Два уровня честности вычислений:** точная многоугольная арифметика
  (суммы Минковского выпуклых кусков через CDT-триангуляцию) для многоугольных
  операций; дуги аппроксимируются с quad_segs=96
- **Самопроверка:** встроенные проверки против аналитических значений
  (разность квадрата — точный квадрат 2a×2a, разность треугольника —
  правильный шестиугольник, и т.д.)

## Установка

Нужен Python 3.10+ с tkinter (в стандартной сборке Windows/macOS есть; на Linux —
`sudo apt install python3-tk`).

**Linux / macOS:**

```bash
python3 -m venv .venv
.venv/bin/pip install matplotlib shapely numpy
```

**Windows (PowerShell или cmd):**

```powershell
python -m venv .venv
.venv\Scripts\pip install matplotlib shapely numpy
```

## Запуск

```bash
.venv/bin/python transform_studio.py                 # окно (нужен дисплей)
.venv/bin/python transform_studio.py --preset star   # стартовая фигура
.venv/bin/python transform_studio.py --svg shape.svg
```

Windows: `.venv\Scripts\python transform_studio.py`.

## Проверка математики (без дисплея)

```bash
.venv/bin/python transform_studio.py --selfcheck   # 9 проверок против аналитики
.venv/bin/python transform_studio.py --smoke       # рендер всех 30 комбинаций фигура×операция
```

## Управление

- **Вершины** (красные точки на левом контуре) — тащить мышью
- **Фигура** — пресеты и «Загрузить SVG…»
- **Операция** — переключение шести операций
- **Элемент B** — круг/квадрат, слайдер размера; «Точки» — плотность выборки для анимации
- **Играть / Пауза** — анимация построения; слайдер «Анимация» — прокрутка вручную

## Файлы

- `transform_studio.py` — вся лаборатория (геометрия + SVG-парсер + GUI)
- `difference_sets.py` — исходное Manim-видео про разностные множества
